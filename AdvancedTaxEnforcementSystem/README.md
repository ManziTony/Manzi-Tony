# Advanced Tax Enforcement Management System (RRA Focus)

## Description
This Java-based system is designed to help the Rwanda Revenue Authority (RRA) manage and enforce tax compliance for three main tax types: PAYE, VAT, and Withholding Tax. It applies Object-Oriented Programming principles including Abstraction, Encapsulation, Inheritance, and Polymorphism.

## Features
- Declare taxes (PAYE, VAT, Withholding)
- Validate declarations and enforce compliance
- Calculate tax and penalties
- Generate receipts and audit summaries
- Maintain taxpayer and tax officer records

## Structure
- One main class: `AdvancedTaxEnforcementSystem`
- Abstract class: `TaxDeclaration`
- Concrete classes: `PAYEDeclaration`, `VATDeclaration`, `WithholdingTaxDeclaration`
- Encapsulated classes: `Taxpayer`, `TaxOfficer`
- Interface usage: `TaxCalculable`, `Receiptable`

## How to Run

javac AdvancedTaxEnforcementSystem.java
